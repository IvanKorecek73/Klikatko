# Archiv starého lokálního spouštěče

`Start-Klikatko-Local.cmd` je nezměněná záloha dosud necommitnutého souboru ze staré
kopie `_klikatko`, pořízená 11. 9. 2026. Obsahuje historický port 5095 a cestu k Node.js
na původním zařízení. Nespouštět jej z tohoto archivního adresáře.

Pro další práci používej spouštěče v kořeni repozitáře a port 5096. Druhý neversionovaný
soubor staré kopie, `public/favicon.ico`, je bajtově totožný s již versionovanou ikonou
tohoto repozitáře (SHA256 `FDF4801EF293109BC0EE9871BBE27CED4C43C3346FDB992911F10DB195B4ABC9`).
Commit staré kopie `3d6ece6` je předkem aktuální historie; žádné další unikátní commity
nebo pracovní změny v ní při této kontrole nebyly.
