PID Litačka BE — dokumentace API

Statická dokumentace REST API backendu pid-litacka-2.0-backend, generovaná průchodem zdrojového kódu (controllery, MediatR handlery, MOS klienti, repository) k datu 2. 7. 2026. Nejde o Swagger — stránka není napojená na běžící API a nic z ní nelze volat. Navíc u každé návratové hodnoty popisuje, odkud pochází: z Core MOS (SOAP/REST), z lokální databáze, jde o hodnotu dopočítanou v handleru, z JWT tokenu, nebo z externí služby (Firebase, Naseptávač/Photon, IPT).

Pokud se BE mezitím změnil, dokumentace to nereflektuje — ověřuj proti aktuálnímu kódu v pid-litacka-2.0-backend, zejména u komplexnějších plateb a kupónových toků.
