Gateway / MOS návratová URL

Tato stránka zobrazí celou návratovou URL, query string, hash fragment, POST tělo a jednotlivé položky v tabulce. Hodí se pro návraty z platební brány, aktivační odkazy z MOS e-mailů a obnovu nebo změnu hesla.

Použití jako redirect URL:

POST tělo (např. data z platební brány) se zachytí přes service worker — nech stránku nejdřív jednou načíst (GET), aby se worker zaregistroval; teprve potom se POST návrat zobrazí.
